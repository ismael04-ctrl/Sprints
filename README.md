## 📖 Descripción

Este proyecto busca digitalizar y facilitar el trabajo de los transportistas y de quienes los gestionan, permitiendo organizar envíos, rutas, vehículos y entregas desde un único lugar.

## 🎯 Objetivos

- Centralizar la información de transportistas y vehículos.
- Optimizar la asignación de rutas y envíos.
- Hacer seguimiento del estado de cada entrega.
- Generar informes y métricas de rendimiento.

## ✨ Funcionalidades

- [ ] Registro y autenticación de transportistas
- [ ] Gestión de vehículos y documentación
- [ ] Asignación de rutas y envíos
- [ ] Seguimiento del estado de las entregas
- [ ] Historial de viajes
- [ ] Panel de administración
- [ ] Informes y estadísticas

## 🔄 Metodología de trabajo

Trabajamos con **Scrum**, adaptado a GitHub:

- **Issues**: cada tarea o historia de usuario es un issue.
- **Milestones**: cada sprint es un milestone con fecha de inicio y fin.
- **GitHub Projects**: tablero Kanban con las columnas `Backlog` → `To do` → `In progress` → `In review` → `Done`.
- **Pull Requests**: todo cambio se integra mediante PR con al menos una revisión.
- **Duración del sprint**: `[1 / 2 semanas]`.

## 🌿 Flujo de ramas y commits

**Ramas**

- `main`: versión estable.
- `develop`: integración del trabajo del sprint.
- `feature/nombre-de-la-tarea`: desarrollo de cada funcionalidad.
- `fix/nombre-del-error`: corrección de errores.

**Mensajes de commit**

```
feat: añade formulario de registro de transportistas
fix: corrige error en la asignación de rutas
docs: actualiza el README
```
